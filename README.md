Game_Click The Target
Click the Target is a fast-paced reaction game that tests the player’s speed and accuracy. A target appears at random positions on the screen, and the player must click it as quickly as possible before it disappears. Each successful click increases the player’s score, while missed targets reduce the remaining time.

The game runs on a countdown timer, encouraging quick decision-making and hand-eye coordination. As the game progresses, the target appears faster and in more unpredictable locations, increasing the difficulty and keeping the gameplay engaging.

This game is built using HTML for structure, CSS for styling and animations, and JavaScript for game logic such as random positioning, scoring, and timing.

Technologies used

HTML (HyperText Markup Language)
Used to create the structure of the game, including the game area, score display, timer, and buttons.

CSS (Cascading Style Sheets)
Used for styling the game interface, designing the target, positioning elements, and adding animations or visual effects.

JavaScript
Used to control the game logic such as random target movement, score counting, time management, and user interactions through mouse clicks.

Instructions to run the game

Download or Clone the Repository

Download the project files or clone the repository from GitHub to your computer.

Open the Project Folder

Make sure the folder contains the following files:
index.html, style.css, and script.js.

Open the Game in a Browser

Double-click index.html

OR right-click index.html and choose Open with → Google Chrome / Firefox / Edge

Start Playing

The game will start automatically once the page loads.

Click the target as fast as possible to score points before time runs out.

Restart the Game

Refresh the browser page to restart the game.
